How It Works

Up and running in 20 minutes

Clone the repo, follow the guided setup, and your personal AI is live on Telegram.

Create Your Bot

Get a bot token from Telegram's BotFather. Takes 60 seconds.

Set Up Memory

Connect Supabase for persistent memory with semantic search and embeddings.

Personalize

Tell Nova about yourself — your name, timezone, workflow, and communication style.

Go Live

Run it as a background service. It's always on, always learning, always ready.

Capabilities

From free relay to full AI infrastructure

Start with the essentials. Unlock the full platform when you're ready.

  • 6 Specialized AI Agents

    Research, Content, Finance, Strategy, Critic, and General orchestrator working together.

  • Real Integrations

    Gmail, Google Calendar, and Notion connected through MCP for real data, not patterns.

    Nova takes actions but asks first via inline Telegram buttons. You stay in control.

    Your bot speaks back via ElevenLabs. Calls you when something is urgent.

    Cloud server that never sleeps. Hybrid mode: free local when awake, API when sleeping.
